# 見た目と操作の仕様

本家 NEXUS for UEC（`com.bookmark.nexusforuec`）の配色・密度・部品を、APK とストアの実画面から取り出して
OpenYASKE の Compose 実装に移した記録。数値の出どころは 2 つある。

- 配色と寸法: `uec-universal.apk` の smali にある色定数と dp 定数
- 画面構成と密度: Google Play のスクリーンショット（1080px 幅を 390dp 端末として換算）

## 色

本家は Material 3 の既定（紫）ではなく、濃紺と藍の独自パレットを使う。

## 寸法

- 画面の左右余白 16dp、カード内 16dp、節の上 24dp / 下 8dp
- ヘッダー 56dp（横画面 44dp）、丸アイコンボタン 40dp、右のスロットは 40dp の倍数
- 角丸は 4 段だけ: control 10dp / card 16dp / sheet 28dp / pill 50%（`AppShapes`）
- 線 1dp。影は使わない。浮かせるのは下部ナビだけ
- 下部ナビ 80dp（横画面 48dp・ラベル無し）、画面下の余白は 96dp（横 72dp）
- TODO の行 56〜64dp、区切りは 1dp の線
- 時間割のセル 104dp、カレンダーの日セルは残り高さから 96〜132dp

## 見出しと面の使い方

- 画面名を本文でもう一度書かない。ホーム・TODO・時間割・カレンダー・さがすは下部ナビが現在地を示す
- 押して遷移する画面（設定・GPA・科目詳細）だけ、戻るボタンと題を出す
- 面は 3 種だけ: 地 `background`、面 `surface` + 1dp の線、強調面 `primaryContainer`
- 科目色は 16%（暗所 24%）の重ねだけを使う
- 節の見出しは文字だけ。帯も線も置かず、上 24dp / 下 8dp の余白で区切る
- 1 つの面に 1 つのリスト。行ごとにカードを並べない
- 面の線は使わない。面の色と余白で分ける。区切りは 1dp の線か 24dp の余白
- 角丸はカード 16dp、セル 10dp、シート 28dp。入れ子は外側 − 余白で計算する
- 入力欄は白面 + 1dp の線（地と同系色では境目が見えないため）

## 画面の組み立て

### その他

下部ナビの 5 番目は「その他」。シラバス検索・GPA・設定をここにまとめ、
画面名を繰り返さないため見出しは置かない。増えた機能はこの 1 枚に足す。

### ホーム

1. ヘッダー（左に設定、中央に「ホーム」）
2. 今日のカード: 日付、曜日、今日のコマ数、次の授業
3. 見出し帯「授業関連」+ 3 列のアイコンタイル 6 個
4. 見出し帯「今日」+ 授業・課題・学事の一覧
5. 見出し帯「今後」+ 期限が近い課題
6. データが空のときだけサンプル投入の行

### TODO

1. ヘッダー（未完了・完了・すべてのタブと件数、右に検索）
2. 検索欄（タブの下、白面 + 1dp 線、開いたらフォーカス）
3. 期限でまとめた一覧（期限切れ・今日・今後・期限なし）
4. 丸いチェック、題、科目名と期限、科目色の点、右端のメニュー（編集・削除）
5. 一覧の末尾に追加行、右下に Cookie 形の追加ボタン

### 時間割

1. ヘッダー: 設定、学期のピル、追加
2. 曜日の見出し（白の角丸セル）。左上に 6-7 限のトグル
3. 時限ごとの行。左に開始・終了時刻と時限番号、右に 5 日分のセル
4. 時間割外の科目、合計単位数、科目追加の行

### カレンダー

1. ヘッダー: 前月、年月（タップで今日へ）、翌月、全体設定への歯車
2. 日曜始まりの 6 週グリッド。日付は左上、今日は塗り、選択日は濃紺
3. 日セルに最大 3 本の文字入り帯と `+n`
4. 日を押すと日詳細シート。予定を追加するボタンと「表示」への行
5. 表示の ON/OFF は日詳細シートからボトムシートで開く（設定にも同じ項目がある）

### さがす

1. 題名と説明
2. 検索欄（角丸 10dp、白面 + 1dp 線）
3. 年度・学期・曜日・コマ・課程のドロップダウン
4. 入力が空のときは履修中の科目、入力後はシラバスの結果（200ms のデバウンス）
5. 各結果に「追加」。追加済みは文字に変わる

### 成績の表記

内部は `GpaGrade`（S/A/B/C/F と 4.0〜0.0）だけで持つ。表示は設定で 3 つから選ぶ。

| 表記 | 5 段階 |
| --- | --- |
| SABCD | S / A / B / C / D |
| 秀優良可不可 | 秀 / 優 / 良 / 可 / 不可 |
| 数値 | 4.0 / 3.0 / 2.0 / 1.0 / 0.0 |

`GradeCatalog` が相互変換を持ち、入力はどの表記でも受ける（「秀」「S」「4.0」は同じ S）。

### 科目詳細（ボトムシート）

出欠率、5 状態の内訳バー、今日の出欠を 4 つのボタンで記録、授業回、課題、成績。

## 本家から変えたところ

- 5 つの下部ナビは維持。幅 720dp 以上で左のレールに切り替える
- 設定を 1 か所に集約（本家はホーム・時間割・カレンダーに分散）
- シートとダイアログの戻るを 1 段に統一
- 通知・アカウント・レビュー・求人・管理画面は持たない
- 空セルのタップで科目追加、カレンダーの年月タップで今日へ戻るなど、本家にない近道を足した

## 画面の広さへの対応

- 幅 720dp 以上で左のレールに切り替える
- 幅 900dp 以上（タブレット・横画面）のカレンダーは、月グリッドと選択日のパネルを並べる
- 高さ 560dp 未満では、ヘッダーを詰め、日セルを低くして帯を 2 本までにする
- ホーム・設定・TODO・さがす・GPA は読みやすい幅（760〜880dp）で中央に寄せる
- ホームのタイルは幅に応じて 3 列と 6 列を切り替える

## 学内リンク

本家の APK に入っていた URL をそのまま使う。授業・学習、キャンパス、生活・進路の 3 グループを折りたたみで並べ、
タップは OS のブラウザで開く（`LocalUriHandler`）。

## テーマ

システム / ライト / ダーク / ピュアブラックの 4 つ。ピュアブラックは有機 EL 向けで、地を `#000000`、
面を `#0B0B0C`、線を `#26262B` にする。面の差だけでなく、1dp の線も併用して境目を作る。

アクセントは 1 色だけ選べる（プリセット 8 色 + RGB のスライダー）。選んだ色から
`primary` / `primaryContainer` / `on-*` / `sectionBar` / 「地」の色相を導出する。
明度と彩度は系統ごとに固定するので、ライト・ダーク・ピュアブラックのどれでも
文字とのコントラストが崩れない。

## ホームの並び

0. ヘッダー（左にアプリアイコンとアプリ名、右に設定への歯車）
1. 今日のカード（大きな日付・コマ数・次の授業・1 日の進み具合のリング）
2. よく使うリンク（本家のリンク集。最初の 4 件だけ開く）
3. 今日の予定
4. 今後（横画面では「今日」と 2 列に並べる）

GPA への導線は時間割の合計単位数バーに移した。

下部ナビと同じ行き先を上に並べない。ホームに置くのは、ナビから届かないもの（リンク、GPA）だけ。

## アイコン

`ui/design/AppIcons.kt` に意味ごとの 1 絵柄だけを持つ。TODO は `Checklist`、時間割は `CalendarViewWeek`、
カレンダーは `CalendarMonth`。行末の開示は文字の「›」ではなく `Disclosure()`（18dp）に統一する。

## Material 3 Expressive

デザイン言語は M3E に寄せる。iOS 風の浮遊ピルはやめ、下部は端まで届く `NavigationBar` と
ピル型インジケータにした。成績の 5 段階は `ButtonGroup` + `ToggleButton`、追加ボタンは
`MaterialShapes.Cookie9Sided`。

`ShortNavigationBar`（M3E の新しい下部ナビ）は、この構成では 1 項目しか描画されなかったため採用していない。


アプリバーは `TabHeader`（タブ画面）と `AppTopBar`（下位画面）の 2 種だけ。
文字は 6 ロールに固定し、数字は `tabular()` で等幅にする。

`MaterialExpressiveTheme` を使う。stable の material3 1.9.0 では内部扱いなので、
`org.jetbrains.compose.material3:material3:1.11.0-alpha07` を明示して有効にしている。
動きは `MotionScheme.standard()`（跳ねない）。追加ボタンだけ `MaterialShapes.Cookie9Sided` の形にして、
M3E らしさを 1 か所に置いている。

## フォントの読み込み

本文は 3 段階で読む。

1. `*_ui.ttf`（約 330KB）: `ui/strings` の文言と、かな・記号・ラテン文字だけを含むサブセット
2. `*_content.ttf`（約 820KB）: 同梱シラバスの科目名・教員名まで含む
3. フルフォント（9.2〜17.8MB）: ユーザー入力の稀少な漢字を補う

Compose の `FontFamily` はグリフ単位のフォールバックをしないため、2 つ並べても欠けた文字は出ない。
そこで `Res.readBytes` でフルフォントの取得完了を待ち、完了したら家族ごと差し替える。
差し替え中も文字の位置はほぼ動かない。

## 既知の制約

- Web は日本語フォント 9.2MB を取得する。UI の文言はサブセットで先に出るが、
  科目名はフルフォントが届くまで欠ける（一瞬）。Android はアセット同梱なので影響なし
- 中国語フォントは 17.7MB。中国語を選んだときだけ取りに行く
- 本家の天気カードと学内リンク集は、外部 API と外部ブラウザに依存するため未実装
